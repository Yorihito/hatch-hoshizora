# hatch-hoshizora

星空マップ

自分の場所から見える星空をシミュレーションできるWebアプリ
星座もでたり、惑星の位置がわかったり、月の満ち欠けがわかったり
月日や場所の指定もできる

---

このリポジトリは [Hatch](https://hatch.nyoyapoya.cc/ideas/d03c52c4-e27b-4b8f-9aec-285bfe0d88f3) のアイデアから生成されました。
仕様は Issue を参照してください。

## 動かす

```bash
npm install
npm run dev
```

http://localhost:3000 で開きます。
